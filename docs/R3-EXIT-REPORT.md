# R3 出口验收报告

版本：`1.0.0-r3.complete`

## 结论

R3 本地可玩 Web MVP 已达到阶段出口门槛。两名玩家可以从首页配置对局，在同一浏览器内完成私密交接、完整规则对战、结算与再战。

## 交付范围

- 首页与对局设置：标准／基础模式、先手阵营和确定性种子。
- 九线桌面：点击与拖放部署、合法目标、占旗、补牌和事件反馈。
- 完整战术交互：士气、环境与诡计牌，包含多步骤效果。
- 本地双人：换手隐私门、主动隐藏、自动存档、刷新恢复、结算和交换先手再战。
- 响应式：1440×900、1280×720 与 844×390 目标视口无横向页面溢出。

E2E 明确覆盖：

- 突破三线与包围五线两种胜利路径。

- 标准／基础模式与双方先手设置。
- 换手 DOM 防泄漏、自动存档恢复、拖放与三种目标视口。

## 人工浏览器验收

- 配置页可选择基础模式、朱羽先手与自定义种子。
- 对局创建后先进入朱羽交接门。
- 交接门中手牌节点为 0、战场节点为 0，HTML 不包含部队牌 ID。
- 接管后显示基础对局、战术牌堆 0、朱羽行动与 7 张本人手牌。

## 已知环境事项

项目已配置 Chromium、Firefox、WebKit 三套 Playwright 工程。本机 Firefox 与 WebKit 运行时下载因当前网络长时间停滞而未完成；这两套执行结果不计入本报告的通过数字，后续可在依赖齐备的 CI 或本机补跑 `pnpm run test:e2e`。

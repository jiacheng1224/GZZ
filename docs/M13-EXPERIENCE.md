# M13-C 体验打磨与复盘

版本：`1.5.0-r5.m13c`

核心版本：`1.2.0-r5.m13.review`

## 目标

完成 R5 的非规则体验范围：为关键动作提供可选反馈，让动态效果可以安全关闭，并在终局提供可验证的统计与复盘入口。

## 音效与动态效果

- 音效默认关闭，只有用户在“体验设置”主动开启后才创建 Web Audio 上下文。
- 部署、战术、占旗、回合流转和胜利使用短促的合成提示音，不依赖外部音频素材或网络资源。
- 卡牌落位、占旗和 AI 推演提供轻量 CSS 动效。
- “减少动态效果”会停用动画、过渡和自动平滑滚动，并写入独立本地偏好。
- 即使没有开启应用内选项，系统 `prefers-reduced-motion` 也会自动停用动画。

体验偏好使用 `guzhanzhen.experience.v1`，与对局存档分离；损坏偏好会安全回退到“静音、正常动效”。

## 统计与复盘

核心新增纯函数 `buildGameReview(state)`。它只接受已结束的 `GameState`，逐条归纳事件流并返回：

- 双方部队部署、战术使用、补牌和占旗数量；
- 首次占旗及其事件序号；
- 胜者最后一次占旗形成的制胜节点；
- 占旗领先易手次数；
- 胜者是否曾在占旗数上落后。

结算页展示双方统计表和“首旗／胜负手／走势”三条摘要。所有结果都可由 M12 回放事件重新计算，不新增不可验证的客户端统计状态。

## 修复

单人旧存档返回设置页或再战时，统一由 `beginNewGame()` 强制玄甲先手，避免“朱羽先手已选中”与单人规则文案冲突。

## 自动化验收

- `buildGameReview()` 覆盖统计、领先易手、逆转和未结束状态拒绝。
- Chromium 验证体验设置开关、本地持久化和 HTML `data-reduced-motion` 状态。
- 两种胜利路径均验证统计表与关键复盘摘要。
- 音效开关不影响规则命令、存档、回放或 AI 行动。

# M16-I 中英双语战场手册

## 目标

把项目早期整理的中英文规则知识转化为游戏内可访问的双语规则速查，并为后续完整本地化建立清晰边界。

## 本次交付

- 规则抽屉新增中文／English 即时切换，默认保持简体中文。
- 双语覆盖胜利条件、回合顺序、五级阵型、夺垒证明、三类谋策和特殊规则。
- 英文阵型示例使用通用颜色与数字表达，不要求玩家理解中文六旌名称。
- 补充谋策数量限制、单局统帅限制、烟障与陷辙的特殊结算说明。
- 语言选择仅存在于规则抽屉组件状态，不写入对局、存档、回放或用户偏好。

## 术语边界

- 中文侧继续使用《烽垒九章》的工作名称与原创术语。
- 英文侧用于解释稳定机制：Flag、Troop、Tactic、Formation、Claim。
- 本阶段不是整款游戏的英文发行版；卡牌正式英文命名、品牌本地化和语言包架构仍属后续工作。
- 双语文字只解释规则，不参与规则引擎计算。

## 验收

- 应用版本为 `2.9.0-m16i`，SSR 显示 M16-I 且不包含手牌身份。
- 中英文均覆盖五类阵型、两条胜利路径及特殊规则。
- 类型检查、Lint、全部单元测试、生产构建和 Worker SSR 通过。

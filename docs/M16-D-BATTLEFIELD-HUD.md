# M16-D 战场 HUD 视觉统一

## 目标

将 M16-C 主菜单建立的九垒地图、六旌、墨绿与旧金视觉语言延伸到实际对局桌面，使“进入战场”后的产品识别保持连续，同时不改变规则核心、存档、回放和联机协议。

## 本次交付

- 游戏桌面复用内容包提供的主视觉资源变量，叠加暗色战场遮罩，保证牌面与操作信息优先可读。
- 为玄甲、朱羽补充独立印记和强调色，用于当前行动者、对手牌架及烽垒归属反馈。
- 九座烽垒加入两位编号、烽火标志、归属光晕和合法目标高亮；“宣告”展示术语统一为“夺垒／争取”。
- 牌背、顶部战况栏和右侧“阵令”面板采用统一边框、印章与材质层级。
- 主题图片路径进入 `game-content` 的 CSS 变量，不再由页面样式硬编码，便于后续替换正式美术。

## 边界

- 未修改 `game-core` 规则、命令、事件与胜负判定。
- 未修改本地存档键、回放格式、在线房间协议或状态投影。
- 当前背景仍为用户提供参考素材的网页优化版本；正式发行前仍需完成资产来源、玩家测试和法务确认。

## 验收

- 内容包覆盖两位阵使的单字印记、合法十六进制强调色和主题图片变量。
- 主菜单 SSR 继续不包含任何手牌身份，并显示 M16-D 与应用版本。
- 类型检查、Lint、全部单元测试、生产构建与 Worker SSR 验证通过。

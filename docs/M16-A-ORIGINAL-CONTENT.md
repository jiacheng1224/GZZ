# M16-A 原创内容包

## 目标与边界

M16-A 将玩家可见的品牌、世界观、牌名、阵型名和主题色从规则引擎中分离，形成首个可替换的原创内容包。该增量只改变展示层，不改变卡牌数量、规则判定、协议、存档或回放语义。

当前采用工作名称 **《烽垒九章 · 六旌竞势》**。故事发生在架空的澜原边境：两位阵使围绕九座烽垒调度六支旌团，争夺军情传讯权。名称与设定均为项目原创工作稿；正式商用前仍须完成商标检索、法务审查和玩家测试。

## 内容包接口

- 包 ID：`beacon-ramparts-zh-cn`
- 内容版本：`0.1.0-m16a`
- 规则集 ID：`nine-fronts-v1`
- 实现位置：`packages/game-content/src/index.ts`
- 接入原则：底层稳定 ID 继续服务规则、协议、存档和回放；UI 只通过内容包读取玩家可见名称。
- 主题原则：主题色通过 CSS 自定义属性注入，不在组件内复制另一套颜色常量。

## 阵型与术语

| 规则 ID     | 玩家可见名称 | 说明                 |
| ----------- | ------------ | -------------------- |
| `wedge`     | 贯锋         | 同旌且连续           |
| `phalanx`   | 同序         | 点数相同             |
| `battalion` | 同旌         | 旌色相同             |
| `skirmish`  | 连步         | 连续但不限旌色       |
| `host`      | 集阵         | 其他组合，比较总点数 |

核心术语采用“烽垒、阵兵、谋策、列阵、争取烽垒”；两方阵使称为“玄甲”和“朱羽”。

## 主题规范

主题 `beacon-night` 使用炭青夜色、旧纸、朱砂、哑金和松绿。变量由内容包挂载到页面根节点：`--background`、`--surface`、`--surface-raised`、`--paper`、`--paper-deep`、`--foreground`、`--ink`、`--muted`、`--line`、`--cinnabar`、`--gold`、`--pine`。

## 来源与版权检查记录

- 玩家可见名称、架空背景和文案均为项目内原创工作稿。
- 本增量未引入外部卡图、音乐、音效或第三方品牌资源。
- 不使用 Battle Line／《古战阵》的品牌标识、原版规则文字、卡面插画、版式或历史人物展示名。
- 旧英文机制名仅作为兼容性稳定 ID 保留，不进入玩家可见界面。
- 工作名称不等于商用名称确认；正式发布前必须另行完成商标、版权与文化表达审查。

## 验收与非目标

自动化验收覆盖内容映射完整性、旧机制名不外露、SSR 品牌元数据和主要浏览器路径。M16-A 不包含规则差异化、音效制作、美术资产包、ID 迁移、玩家研究或正式法务结论。

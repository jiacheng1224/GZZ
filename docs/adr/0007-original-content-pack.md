# ADR-0007：原创内容包与稳定规则 ID 分离

- 状态：Accepted（工作名称待法务确认）
- 日期：2026-08-01

## 背景

规则引擎、回放、AI 和联机协议已经依赖稳定的卡牌、颜色、阵型与阶段 ID。直接重命名这些 ID 会制造不必要的存档和协议迁移，同时玩家界面需要脱离原型期名称，建立原创产品表达。

## 决策

新增独立的 `@guzhanzhen/game-content` 包，以规则稳定 ID 为键提供品牌、世界观、六旌、谋策牌、阵型、阶段、术语和主题变量。首个中文内容包使用工作名称《烽垒九章 · 六旌竞势》。规则核心继续只处理稳定 ID，展示层不得自行维护重复名称映射。

## 后果

- UI 文案和主题可以独立迭代，规则测试、协议与旧存档无需迁移。
- 新语言或新主题可通过新增内容包接入。
- 任何新增机制 ID 都必须同步扩展内容包，完整性测试负责阻止漏项。
- 工作名称、视觉资产和文化表达在正式商用前仍需玩家测试与法务审查。

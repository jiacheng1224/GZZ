# M16-C 游戏主界面

## 目标

将原有“设置表单首页”升级为具有产品识别度的正式游戏主菜单。界面以九座烽垒地图为第一视觉层，保留开始、继续、在线、规则、世界观和设置入口，同时不改变现有对局创建与恢复逻辑。

## 视觉来源与处理

- 参考素材：用户于 2026-08-02 提供的《Codex Image Aug 2, 2026, 01_26_33 AM.png》；项目内保存为传输优化后的 `public/main-menu-art.jpg`。
- 来源状态：用户提供项目素材；未声明第三方版权归属，正式商用前仍应纳入资产来源复核。
- 网页仅使用地图中段与下段作为背景，通过裁切、暗角和文字层构建界面。
- 品牌名与“六旌竞势”副标题由 HTML 文本独立渲染，不依赖图片中的字形，因此可访问、可检索且不会继承参考图的文字误差。

## 信息架构

1. 顶栏：品牌缩略标识、规则、世界观和设置。
2. 主视觉：产品名、副标题、核心定位和“九垒／六旌／约 20 分钟”概览。
3. 部署令面板：四种对局模式、AI 难度、先手、种子、开始与继续。
4. 联机入口：与本地开始按钮同组，但保持次级视觉层级。
5. 页脚：自动存档、确定性牌序和内容版本。

## 交互与响应式

- 所有既有模式、种子、先手、继续存档和在线房间回调保持不变。
- 桌面横屏使用“左侧主视觉 + 右侧部署令”双栏结构。
- 680 px 以下切换为纵向内容，背景固定，主菜单面板取消内部滚动。
- 控件继续使用原生按钮、单选框与输入框；焦点样式和辅助入口均保留可访问名称。
- 用户设置了减少动态效果时，不依赖背景动画传达任何状态。

## 性能与验收

- 背景由 1731×909 PNG 转为 82% 质量 JPEG，从约 2.7 MB 降至约 623 KB；原始文件不修改。
- 首屏标题、副标题与主要操作不写入位图。
- SSR 必须包含 M16-C 标识、正式产品标题和应用版本。
- 类型检查、Lint、内容／规则单测与生产构建必须全部通过。

## 非目标

本阶段不重做对局桌面、不新增账号大厅、不变更规则，也不将参考图直接认定为最终商用美术。社交分享图继续保持独立资产流程。

# M16-J 键盘战场命令

## 目标

为桌面玩家和键盘用户提供可发现、可撤销且不绕过规则引擎的九垒快捷操作。

## 本次交付

- 本地、AI 与在线棋盘支持数字键 `1`–`9` 执行对应烽垒当前合法命令。
- `Escape` 在选牌状态下取消选择，不产生规则命令或事件。
- 本地与在线行动面板显示快捷键提示；烽垒行动按钮声明 `aria-keyshortcuts`。
- 数字键可覆盖部署、目的地选择和夺垒，但只在对应命令已经存在于 `legalCommands` 时执行。
- 在线快捷键仍通过既有 `sendCommand` 提交，并由服务端权威验证。

## 安全边界

- 输入框、文本区、下拉框、可编辑区域和文本框角色获得焦点时禁用全部棋盘快捷键。
- `Ctrl`、`Alt` 或 `Meta` 组合键不被游戏拦截。
- 设置、规则、内容、回放抽屉打开时，本地快捷键暂停。
- 交接遮罩、AI 回合、终局和未接管私密棋盘时不会注册本地命令。
- 快捷键不新增命令类型，不修改存档、回放或在线协议。

## 验收

- 应用版本为 `2.10.0-m16j`，SSR 显示 M16-J 且不包含手牌身份。
- `Escape` 清除选牌；数字键只执行对应烽垒合法命令。
- 类型检查、Lint、全部单元测试、生产构建和 Worker SSR 通过。

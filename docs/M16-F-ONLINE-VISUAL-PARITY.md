# M16-F 在线战场视觉与信息对齐

## 目标

让在线房间和权威投影棋盘使用与本地／AI 对局一致的阵使身份、卡牌、烽垒摘要和移动导航，避免玩家切换模式后重新学习信息层级。

## 本次交付

- 在线入口与房间更新为 M16-F 品牌层级，并复用九垒地图主题背景。
- 房间席位显示玄甲／朱羽印记、在线状态和准备状态；行动条显示当前阵使印记。
- 对手手牌使用统一牌背和数量呈现，不进入任何卡牌身份信息。
- 在线九垒显示烽火、两位编号、占领者、敌我成阵摘要和环境效果。
- 已占领与合法目标使用与本地棋盘相同的身份色和边框反馈。
- 在线行动区显示选中手牌、合法目标数量和“服务端权威确认”说明。
- 移动端复用九垒快速定位条，定位只改变视口，不提交游戏命令。

## 协议与隐私边界

- 所有新增信息都来自现有 `PlayerView` 公共字段和 `legalCommands`。
- 未新增 API、房间字段、命令类型、协议版本或持久化数据。
- 对手手牌仍只渲染数量与无身份牌背；牌堆顺序和私密卡牌不进入 DOM。
- 命令仍由服务端权威验证，客户端高亮不作为合法性事实来源。

## 验收

- 应用版本为 `2.6.0-m16f`，SSR 显示 M16-F 且不泄露手牌身份。
- 现有房间创建、加入、准备、重连、命令提交和再战流程保持兼容。
- 类型检查、Lint、全部单元测试、生产构建与 Worker SSR 通过。

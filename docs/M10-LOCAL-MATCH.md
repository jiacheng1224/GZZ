# M10 本地双人对战

版本：`0.9.0-r3.m10`

## 私密交接

- 首次打开页面、刷新恢复和活动玩家改变后，只渲染交接门。
- 交接门不渲染 `PlayerView`、战场、手牌、战局日志或卡牌标识。
- 当前玩家确认接管后才渲染其投影。
- 玩家可在回合中主动选择“隐藏手牌并交接”。

## 本地存档

- 存储键：`guzhanzhen.local-game.v1`。
- 存档信封包含 schema 版本、应用版本、保存时间和完整 `GameState`。
- 恢复前执行 `assertGameState()`；无法解析或违反不变量的存档会被清除。
- 每次状态改变后自动覆盖本地存档，固定种子和事件日志保持可复现。

## 结算与再战

- 结束状态通过 `buildGameSummary()` 生成胜者、胜因和制胜战线。
- 结算页显示双方占旗数量。
- 再战生成新种子并交换上一局先手，随后重新进入私密交接门。

## 浏览器验收

- 换手期间手牌与战场 DOM 节点均为 0。
- 刷新后恢复到完全相同的阶段、手牌数量和战线状态。
- 注入合法结束状态可展示结算，并从结算进入私密再战。
- M09 的点击、拖放、侦察与响应式路径持续通过。

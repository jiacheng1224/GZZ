# M16-E 战术可读性与移动导航

## 目标

在 M16-D 已建立的战场视觉基础上，降低玩家识别卡牌、判断九垒进度和定位合法目标的成本。该增量只使用公开状态和既有合法命令，不改变规则判定。

## 本次交付

- 卡面加入由内容包驱动的六旌／谋策分类印记，完整卡与场上紧凑卡使用同一信息结构。
- 每座烽垒同时显示敌我成阵进度；兵列完成后显示阵型名称与总点数，并正确响应烟障环境。
- 行动令持续显示当前选牌和合法烽垒数量，未选牌时提供下一步说明。
- 680 px 以下提供九垒快速定位条，显示已占领阵使与当前合法目标；点击后使用原生滚动定位到对应烽垒。
- 展示用术语、阵型和印记继续从 `game-content` 读取，规则内部 ID 不暴露给玩家。

## 兼容边界

- `game-core` 的阵型计算仅作为公开桌面摘要读取，没有新增或修改规则分支。
- 本地存档键、回放结构、房间命令、状态投影和服务端数据均未迁移。
- 移动导航是渐进增强；桌面布局和键盘可用的原有行动按钮仍保留。

## 验收

- 应用版本为 `2.5.0-m16e`，SSR 显示 M16-E 且不包含手牌身份。
- 完整与紧凑卡面均有可见文本，印记标记为装饰内容。
- 类型检查、Lint、全部单元测试、生产构建和 Worker SSR 通过。

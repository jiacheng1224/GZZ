# M12 可验证回放与档案

版本：`1.2.0-r4.m12`

## 档案结构

`ReplayArchive` 包含：

- schema 与规则版本；
- 对局种子和完整初始状态；
- 按顺序记录的 `GameCommand`；
- 最终 `GameState` 的 FNV-1a 指纹。

核心通过初始状态重新执行全部命令，并比较最终指纹。非法命令、越界节点、版本／种子不一致和内容篡改都会被拒绝。

## 回放时间线

- `replayTo(archive, commandCount)` 可重建任意命令边界的状态。
- Web 面板支持上一步、下一步和范围滑杆。
- 面板显示命令节点、回合、阶段、事件数、九条战线与最近公开事件。
- 重演不会修改档案、初始状态或当前真实对局。

## 信息安全

- 活动对局只通过 `projectForSpectator()` 展示公开信息。
- 公开回放不展示任何玩家手牌、牌堆顺序或私密抽牌内容。
- 活动对局禁止生成完整档案。
- 结算后允许导出，并提示档案包含双方隐藏信息，应谨慎分享。
- 导入档案完成校验后，未结束对局重新进入私密交接门。

## 本地存档兼容

- 新存档同时保存回放初始状态与命令历史。
- 恢复时验证命令重演的最终状态与保存状态一致。
- M12 之前的旧存档以当前状态作为回放初态，安全降级为单节点回放。

## 自动化验收

- 核心覆盖前进／后退、往返序列化、直接执行一致性与三类篡改拒绝。
- Playwright 覆盖活动局公开回放、前后移动、导出禁用，以及结算档案生成和重新导入。
- M09–M11 的桌面、隐私、战术、胜利与教学路径持续回归。

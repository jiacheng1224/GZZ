# R6 RC1 出口加固

版本：`2.0.0-r6.rc1`

## 目标

为邀请制在线对战 Beta 补齐上线前的滥用防护、生命周期清理和 HTTP 全链路稳定性证据。RC1 表示功能闭环已形成，但在真实 Sites 部署、50 局部署环境对局和弱网人工验证完成前不标记 R6 正式发布。

## 数据库原子限流

`room_rate_limits` 按操作、固定时间窗和匿名化请求来源生成桶键。来源由 Cloudflare 客户端地址与会话授权头共同计算 SHA-256，仅保存不可逆摘要。

默认一分钟窗口：

- 创建房间：12 次；
- 加入房间：30 次；
- 已认证房间动作：180 次；
- ETag 条件同步不计入写操作限流。

计数通过单条 D1 `INSERT ... ON CONFLICT ... RETURNING` 原子增加，跨 Worker 实例共享。超限返回 `429 RATE_LIMITED`、`Retry-After: 60`，并记录不含身份和令牌的结构化事件。

## 生命周期清理

- 定时 Worker 入口每批最多删除 500 个过期或已标记过期的房间；
- 同时删除已过期的限流桶；
- 创建新房间时异步执行最多 50 个房间的小批量机会清理，即使托管环境暂未配置定时触发器也能逐步回收；
- `expires_at` 和限流桶过期时间均有数据库索引；
- 清理日志只记录删除数量。

## 并发与弱网语义

- 两个相同修订号的并行请求只能有一个成功写入；
- 并行重复命令中，一个请求推进状态，另一请求获得 `409`；
- 冲突方取得最新房间后，用同一命令 ID 重试会得到 `duplicate`，不会重复行动；
- HTTP 对局压测周期性执行断线、重连和确认包重复提交。

## 自动化证据

- 50 局 M15-A 权威状态机对局全部完成；
- 12 局双客户端 HTTP 全链路对局全部完成；
- 每局使用在线同步快照驱动标准 AI，而不是直接读取状态选择命令；
- 压测覆盖周期性断线恢复、幂等重复和 500 步死锁上限；
- API 测试覆盖限流响应、重试提示、批量清理和并发冲突；
- 全量单元、页面回归、构建和 SSR 门禁继续执行。

## R6 正式出口待办

- 发布到带真实 D1 的 Sites 私有环境；
- 部署环境连续 50 局双客户端对局；
- 两个真实浏览器完成人工标准对局与再战；
- 模拟高延迟、短时断网、确认包丢失和标签页刷新；
- 核对生产限流、清理和错误指标；
- 完成后标记 R6 Beta，并进入 M16 原创内容与版权边界阶段。

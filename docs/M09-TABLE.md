# M09 Web 游戏桌面

版本：`0.8.0-r3.m09`

## 输入边界

桌面组件通过 `projectForPlayer()` 读取当前玩家的 `PlayerView`。手牌、事件、待处理战术和合法动作均来自投影；组件不自行判定阵型、占旗、战术目标或胜利。

## 已支持交互

- 九条战线、双方阵型槽位、环境牌与占领状态。
- 当前玩家手牌、对手手牌数量、部队／战术牌堆和弃牌数量。
- 点击选牌后选择高亮战线。
- 将手牌拖放到战线；与点击使用同一命令入口。
- 宣告战线、结束宣告、双牌堆补牌和无牌跳过。
- 侦察、重新部署、逃兵与叛徒的分步选择、弃置与取消。
- 当前玩家权限下的脱敏战局记录。
- 种子化新对局入口。

## 验收覆盖

- 首个完整回合：部署、结束宣告、补牌、换手。
- 点击与拖放两条输入路径。
- 侦察的抽 3 张、选 2 张放回完整流程。
- 对手手牌身份不进入可访问 DOM。
- 1440×900、1280×720、844×390 无页面级横向溢出。

## M10 接续状态

M10 已加入交接遮罩、接管确认、本地存档、刷新恢复、结算页和再战。桌面在换手时会从 DOM 完全卸载，确认接管后才重新渲染当前玩家投影。

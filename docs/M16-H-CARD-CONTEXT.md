# M16-H 卡牌上下文与选牌可访问性

## 目标

让玩家在选中卡牌后不离开战场即可理解其作用、确认可用目标并撤销选择，同时让键盘和辅助技术获得完整而一致的卡牌名称。

## 本次交付

- `CardFace` 从内容包读取卡牌描述，为完整卡和场上紧凑卡提供统一的可访问名称与原生说明提示。
- 阵兵说明来自六旌内容条目；谋策说明来自对应谋策内容条目，不在 UI 中维护重复文案。
- 本地／AI 行动令显示选中卡牌的效果说明、合法烽垒数量和“取消选牌”按钮。
- 在线军令显示相同效果说明、服务端权威目标数量和取消入口。
- 未选牌时保留下一步提示；取消选择只清理本地 UI 状态，不提交游戏命令。

## 边界

- 卡牌描述是解释性内容，不参与合法目标、阵型、夺垒或 AI 计算。
- 合法目标数量继续由现有 `legalCommands` 计算，客户端文案不成为规则事实来源。
- 内容注册表结构、规则 ID、存档、回放和在线协议均未迁移。
- 装饰性旌记保持 `aria-hidden`；卡牌名称同时包含名称、分类和效果说明。

## 验收

- 应用版本为 `2.8.0-m16h`，SSR 显示 M16-H 且不包含手牌身份。
- 选牌后显示描述与目标数量，取消后清除选中状态。
- 类型检查、Lint、全部单元测试、生产构建和 Worker SSR 通过。
